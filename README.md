# Labyrinth Game
As it is a school project there are certain things to be done if you want to execute this project (actually not that many).
Get the zip from the "livrables" file and extract it. You should be good with the files that are in it to make the project work.
Alternatively if you use NetBeans (which I doubt) you can import from zip directly.
The PDFs are for school purposes and are not that interesting (unless you want to look at some UML diagrams).
